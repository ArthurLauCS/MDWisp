# 当前状态

0.5.0 起应用为纯 Rust 原生实现（Win32 + Direct2D + DirectWrite + DirectComposition），功能与 0.4.1 的 Electron 版对齐，界面布局、字体与动效按原版移植。

| 内存（工作集 / 私有） | 约 450MB / 340MB | 约 62MB / 35MB |

## 未完成 / 与 0.4.1 不一致

后续版本补齐，补齐后从此处删除。

- **编辑器内公式不渲染**：`$…$`、`$$…$$` 在编辑器里显示为带样式的 TeX 源码；导出的 HTML/PDF 正常渲染。计划方案：内置 QuickJS + MathJax，首次遇到公式时再加载，生成 SVG 后交给现有的 SVG 渲染。
- **拼写检查设置不生效**：设置项保留，编辑器暂无拼写检查。
- **"全选匹配"不可用**：编辑器只支持单选区。
- **14 个无快捷键的表格动作**：五种表格样式、最小值 / 最大值、Excel 粘贴、CSV / JSON / 列表转换、导出 CSV、删除整表，在注册表中保留为不可用。
- **重命名可能覆盖同名文件**：0.4.x 起就存在，重命名前未检查目标是否已存在。
- **无文档时的欢迎页未实现**：启动时总会打开上次的文档或一份空白草稿，实际不会出现这个界面。
- **仅 Windows**：界面直接使用 Win32 / Direct2D，没有 macOS 和 Linux 版本。

## 已知的取舍

- **内置中文字体约 22.5MB**。保留完整字体以覆盖用户文档中的汉字，字体授权随包分发。
- **整理不改写非图片链接**。散装文档里指向旁边其他文件的相对链接（如 `[另一篇](./b.md)`）在移入文件夹后会失效，需要手动处理。
- **整理后的文档是新路径，历史版本不跟随**。历史按路径归档；保留原文件时原文件的历史仍在。
- **不能自行设为默认打开方式**。Windows 只允许用户在系统设置里选择，应用只注册为候选。
- **插件没有做过真实对话的端到端验证**。清单经 `claude plugin validate` 通过，校验脚本有单元测试。
- **表格样式类操作没有存储位置**。markdown 表格语法里没有放样式的地方，需要额外的标记方案。
- **`sortByColumn` 靠首行是否非空来判断表头**。表头单元格本身为空时判断会失准。

## 验证方式

```bash
cargo test --workspace                 # 364 个测试
cargo build --release -p mdwisp        # 发布构建
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dist.ps1   # 安装包，输出到 target/installer/
python scripts/icon.py                 # 改过 build/icon.svg 后重新生成图标与资源
claude plugin validate .               # GitHub 仓库入口
claude plugin validate plugin          # 插件与市场清单
```

界面回归用 `MDWISP_SCRIPT` 驱动真实窗口并截图，格式见 `crates/app/src/script.rs`；截图按轮次存到 `design-review/`。
